    How much of a port this is

    Every level below is about completeness, not safety. A port with every box ticked is still one nobody has driven: AutoDistill cannot test a car, so it never marks a port safe for control.

    Facts AutoDistill cannot observe Human supplied

    These are the gaps listed above. None of them is in the traffic, so they have to be measured or looked up; supply them and the generated port comes out finished instead of inert. Everything here is marked as manual evidence, and none of it marks a port safe for control.

    Measured vehicle specifications
    openpilot CarState bindings

    Bind each openpilot field to a recovered signal. This is how fields a name cannot reveal get filled in — nothing in BRAKE_PRESSURE says which value means the pedal is down. Run the decoder first so the signal lists are populated.

    Actuation, limits, and safety

    Fill these in and AutoDistill generates a working controller instead of an inert one. Every value must come from your own bench work: nothing here is inferable from traffic, and the generated port is still never marked safe for control.
